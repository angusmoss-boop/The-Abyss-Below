## Package checks

The complete ZIP and the update ZIP are checked as archives. Applying the update over the actual v0.17.4 complete ZIP must reproduce all current files and all 17 `version.json` asset hashes. HTML script order, consistent runtime versions and the new `lost-signals.js` are part of current release checks. Approved icon and launch-art bytes are unchanged from baseline.

## Fixtures and visual review

All tests use synthetic campaigns, not a real player save. Migration retains a synthetic v0.17.4 fixture for reproduction when the historical source ZIP is unavailable. New previews come from the production HTML/CSS/Canvas renderer. The Warden preview uses synthetic equipment/progress and a saved encounter with nearby ordinary predators removed to show the resident clearly. It is not evidence of a natural gameplay balance run.

The mobile contract board, import preview and landscape Warden encounter were visually inspected. Tests also capture mobile/landscape/desktop contract layouts and the banked journal. Local preview version status remains unverified; no verified-hosting badge is fabricated.

## Blocked and untested

A real local-HTTP navigation was attempted by `tests/v0180_live_pwa_probe.py` and blocked with **net::ERR_BLOCKED_BY_ADMINISTRATOR**. Therefore real HTTP hosting, actual service-worker installation, live offline launch and an already-installed app moving from v0.17.4 to v0.18.0 remain **unverified**. Mocked worker and version tests do not replace those checks.

Physical Android/iOS performance, device file-picker and download ergonomics, native Android packaging/storage, Safari/Firefox, human sound/music listening, long-session storage limits and a complete human campaign/contract/boss balance playthrough remain untested. The Warden is a first playable encounter, and credit rewards are proposed gameplay tuning rather than a proven optimum.

## Reproduction

Run `python tests/build_release.py` after any runtime edit, then `python tests/run_v0180.py`. Do not modify runtime files during testing. Runtime changes without regenerating hashes correctly fail sync/worker checks. `python tests/preview_v0180.py` produces staged interface/game previews. Dependencies: Python, Playwright, Chromium, Node and Pillow. See `tests/README-v0.18.0.md`.
